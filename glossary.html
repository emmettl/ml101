Glossary

Every term the course uses, in two sentences of plain English. The jargon comes after the idea, never before it.

Activation

The bend applied to a neuron's weighted sum before it is passed on. Without it, any stack of layers collapses into a single straight line. Swap activations in the Network Playground →

Attention

How a word adjusts its meaning to its context: it scores every other word for relevance, turns the scores into shares that add up to 100%, and becomes the share-weighted blend of what those words offer. Steer it in the Attention Lab →

Backpropagation

How a network finds the slope for every knob: one sweep forwards to make a guess, one sweep backwards sharing out the blame along the wires in proportion to the weights. See blame flow in the Network Playground →

Batch

The handful of examples looked at in one step of training. A full batch uses every example; a mini-batch uses a random few, which is cheaper and noisier. Try batch sizes in the Descent Lab →

Capacity

How flexible a model is: roughly, how many different shapes its knobs let it take. More capacity can fit more patterns, and more noise. Raise the capacity in the Overfitting Lab →

Classification

Predicting a category (spam or not) instead of a quantity. The model outputs a probability for each category; turning that into a verdict is a separate decision. Try it in the Neuron Lab →

Context window

How much preceding text a language model can take into account at once, measured in tokens. Attention compares every token with every other, so doubling the window roughly quadruples the work.

Convergence

The point at which further training steps stop changing anything much, because the slope underfoot has flattened out.

Cross-entropy

The usual loss for classification: the average surprise at the right answer, measured as the negative logarithm of the probability the model gave it. Confident mistakes cost the most.

Decision boundary

The places where a classifier is exactly undecided between two categories. For one neuron it is a straight line; for a network it can be any shape.

Dimension

One of the coordinates in an embedding. More dimensions give meaning more independent directions to vary along; too few and different kinds of meaning interfere. Compare 2 and 8 in the Embedding Lab →

Divergence

Training that makes the model steadily worse, usually because the learning rate is too large and every step overshoots. It often ends with the numbers overflowing. Find the edge in the Descent Lab →

Embedding

A token's learned position in space: a list of numbers, trained like any other knobs, such that tokens used in similar company end up close together. Watch one form in the Embedding Lab →

Example

One input paired with the answer we wanted for it. Examples are the only teacher a model has. Also called a data point or a sample.

Fine-tuning

Continuing to train an already-trained model on a much smaller set of examples chosen to shape its behaviour, such as conversations showing what a good answer looks like. Same loss, new examples.

Generalisation

Doing well on inputs the model has never seen. It is the entire point of machine learning, and it cannot be measured on the training examples.

Gradient

One number per knob saying how fast the loss would rise if that knob were turned up a hair. Together they point uphill, so training steps the opposite way. Watch it work in the Descent Lab →

Gradient descent

The training loop: measure the gradient, move every knob a little way downhill, repeat. Nothing more clever than that is happening, at any scale.

Hallucination

Fluent, confident output that is not true. It is not a malfunction: the model was trained to produce plausible text, and plausible is a different property from correct.

Held-out data

Examples kept back from training and used only to score the finished model. Their score is the honest one. See also test set.

Hyperparameter

A setting chosen by a person rather than learned from examples: the learning rate, the batch size, the capacity of the model. Knobs about the knobs.

Language model

A model that, given some text, produces odds for what comes next. Generating text is a loop around it: pick from the odds, append the pick, ask again. Build one from a book in the Next-Token Lab →

Layer

A row of neurons that all read the same inputs. Hidden layers sit between input and output, and what each of their neurons comes to detect is discovered during training, not assigned.

Learning rate

How far to move each knob per step, as a multiple of the slope. Too small and training crawls; too large and it overshoots and diverges. Lengthen the stride in the Descent Lab →

Loss

A single number for how wrong the model currently is across its examples. Training is the business of making this number smaller. This course often calls it the miss. See it as a landscape in the Line Fitter →

Loss landscape

The loss at every possible setting of the knobs, pictured as terrain. With two knobs it can be drawn; with billions it cannot, but descent works the same way. Explore one in the Line Fitter →

Model

A fixed recipe for turning an input into a guess, with adjustable numbers inside it. A straight line is a model. So is a chatbot.

Neural network

Neurons feeding neurons. Early layers carve the input into simple pieces and later layers combine the pieces, all trained together by gradient descent. Train one in the Network Playground →

Neuron

A weighted sum of inputs plus a bias, passed through a bend. On its own it can draw exactly one straight boundary. Meet one in the Neuron Lab →

Noise

The part of the answers that the inputs cannot explain. It sets a floor under the loss that no setting of the knobs can get beneath.

Outlier

An example far from the rest. Under squared loss a single outlier can pull a model a long way, because large misses are counted so heavily. Switch one on in the Line Fitter →

Overfitting

Fitting the noise in the training examples as well as the pattern. The symptom is an excellent training score beside a poor held-out one. Cause it, then cure it, in the Overfitting Lab →

Parameter

One of the adjustable numbers inside a model: a knob. A line has two. Large language models have hundreds of billions. Also called a weight.

Precision and recall

Two ways of scoring a classifier's positive calls. Precision: of those it flagged, how many were right. Recall: of those it should have flagged, how many it caught. Moving the cut-off trades one for the other. Watch the trade in the Neuron Lab →

Pretraining

The first and by far the largest stage of training a language model: predicting the next token across trillions of tokens of text. Almost all of a model's cost and knowledge come from it. Price one in the Scale Ladder →

Query, key and value

The three roles a word plays in attention. Its query is the question it asks, its key is what it advertises to other words' questions, and its value is what it hands over when listened to. All three are computed by learned weights.

Regularisation

Any nudge that makes a model prefer simpler explanations, most often a charge added to the loss for large knob values. It trades a little training error for better generalisation. Apply a penalty in the Overfitting Lab →

Reinforcement learning from human feedback (RLHF)

A later training stage in which people compare pairs of answers, a second model learns to predict their preferences, and the chatbot is nudged towards answers that score well. It makes models more helpful, and more eager to please.

Sampling

Choosing one token from a language model's odds. It is a separate step from the model, with its own settings, and it is where the randomness in a chatbot's replies comes from.

Scaling laws

The observation that a language model's loss falls smoothly and predictably as its size, its training text and its training arithmetic grow together. It is why labs can plan enormous training runs in advance. See the curve in the Scale Ladder →

Sigmoid

An S-shaped curve that squashes any number into the range 0 to 1, so it can be read as a probability. Large positive inputs give nearly 1, large negative nearly 0, and zero gives 0.5.

Softmax

A squashing step that turns any list of scores into positive shares adding up to 100%, with higher scores getting disproportionately more. Used to turn attention scores into attention weights, and a model's raw outputs into odds.

Squared error

A way of scoring a guess: the difference from the right answer, squared. It is always positive and it punishes large misses far more than small ones.

Stochastic gradient descent (SGD)

Gradient descent using a small random batch of examples for each step instead of all of them. The slope is only roughly right, but steps are so much cheaper that it wins easily.

Temperature

A sampling setting that reshapes the odds before a pick is made. Low values favour the likeliest token and make output repetitive; high values give long shots a real chance and make it erratic. Turn it up in the Next-Token Lab →

Test set

Held-out examples scored exactly once, at the very end. If you tune against a held-out set repeatedly you begin to fit it too, so the final exam must stay unseen.

Threshold (cut-off)

How confident a classifier must be before it says yes. It is a policy choice, set by the cost of each kind of mistake, and no amount of training chooses it for you. Move it in the Neuron Lab →

Token

The unit of text a language model reads and writes: a piece from a fixed vocabulary, often a whole common word, often a fragment of a rarer one. Models never see letters or words as such. Tokenise your own text in the Embedding Lab →

Tokeniser

The rule that cuts text into tokens. It is built once, before training, by repeatedly merging the most frequent neighbouring pieces in a large body of text.

Top-k

A sampling setting that discards all but the k likeliest tokens before picking. At k = 1 the model always takes its favourite, which tends to trap it in loops. Set it to 1 in the Next-Token Lab →

Training

Turning the knobs until the loss on the examples is small. The model's recipe does not change during training; only the numbers inside it do.

Transformer

The architecture behind modern language models: embeddings, then many layers that each apply attention followed by a small neural network to every token, all trained together to predict the next token.

Underfitting

A model too stiff to follow the pattern. Both its scores are poor, and close together. More training will not help; more capacity will.

Weight

A knob that scales one input to a neuron. A large weight means the neuron listens closely to that input; a negative one means the input counts against. Weights and biases together are the parameters.
