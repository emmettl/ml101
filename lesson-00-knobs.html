A machine with knobs

Strip away the vocabulary and every model, from a straight line to a chatbot, is the same three things: some knobs, some examples, and a number that says how wrong the knobs currently are.

The one idea

Nobody writes the rules. They turn knobs until the examples fit.

Ordinary software is a list of rules a person wrote down: if the basket is over £50, delivery is free. That works when someone knows the rules. Nobody knows the rules for recognising a cat, or for which word should come next in a sentence. So we do something else. We build a machine whose behaviour depends on a set of adjustable numbers, show it examples of the right answer, and adjust the numbers until its answers stop being wrong.

That is the whole subject. The rest of this course is the same idea with more knobs.

A model is a machine with knobs. Learning is turning the knobs to make the error smaller.
The machine

A fixed recipe that turns an input into a guess. Here: multiply by one number, add another.

The knobs

The adjustable numbers inside the recipe. Engineers call them parameters. A line has two. Large language models have hundreds of billions.

The examples

Inputs paired with the answer we wanted. The only teacher the machine has.

The miss

One number for how wrong the current knobs are across all examples. Its proper name is the loss.

Try it by hand

You are the learning algorithm

Below are 24 examples: say, the size of a flat and what it rented for. The machine is a straight line. It has two knobs. One tilts the line and the other lifts it. Before a computer does this for you, do it yourself: move the two sliders until the line runs through the cloud of points.

Each red square is one example's miss, squared. A guess that is twice as far off draws a square four times the size, so large misses dominate. Your job is to make the total red area as small as you can.

Notice what you did. You never worked out a formula. You nudged a knob, looked at whether the number went down, and kept the change if it did. That loop—nudge, measure, keep—is what training is. The next lesson hands the loop to the computer.

The arithmetic

Why the best possible miss is not zero

However carefully you set the knobs, the miss stops at about 0.88 and will not go lower. That is not a failure of effort. The examples contain noise: two flats of the same size rent for different amounts, for reasons the input does not capture. A straight line cannot pass through both. The part of the error no setting can remove is the honest limit of what this input can tell you.

Reducible error

The knobs are in the wrong place. Turning them helps.

Irreducible error

The world is noisy. No setting of these knobs helps.

Hold on to this. In lesson 02 a more flexible machine will drive the miss to zero on these examples, and it will be a mistake.

Takeaways

What to remember

A model is a recipe with knobs

The recipe is chosen by a person. The knob settings are found from examples.

The loss is one number

It compresses “how wrong, overall” into something you can push downhill.

Learning is nudge, measure, keep

You just did it by hand. Everything later automates and scales that loop.

Zero error is not the goal

Noise sets a floor. Going below it means fitting the noise.
