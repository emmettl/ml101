Next-Token Lab

The bars are the model's entire output: odds for the next character, given the last few. Everything else is a loop around them. Write one character at a time and watch the odds change with every pick, then find the context length at which the model stops composing and starts reciting.

Scope: a character-level model over the first seven chapters of Alice's Adventures in Wonderland (public domain; about 81,000 characters, lower-cased, 33 symbols). It counts what followed each context in the book and backs off to a shorter context when a run was never seen. There are no learned knobs, no embeddings and no attention, so it cannot generalise to contexts it has not met. Real models predict word pieces, not characters, from billions of pages.

    The model only makes odds

    Everything that feels like a decision, including whether to be safe or surprising, is made by the sampler afterwards. That is why the same model can be run “creative” or “precise”.

    One pick changes everything after it

    Each character becomes part of the context for the next. An unlucky pick is never corrected; the text simply carries on from wherever it landed.

    Fluent is not the same as new

    The longest contexts give the best-looking prose and the least original. Judging a model by how polished its output looks rewards exactly the wrong thing. The next lab gives the same job to a neural network, which has too few knobs to recite.

    Going further

    Predicting text from counts of what followed what is Claude Shannon's idea; his 1948 paper “A Mathematical Theory of Communication” prints samples very like the ones in the table. For how neural networks replaced the counts, see Bengio et al., “A Neural Probabilistic Language Model” (2003). On large models reproducing their training text, see Carlini et al., “Extracting Training Data from Large Language Models” (2021). The text is Lewis Carroll's, from Project Gutenberg's public-domain edition.
