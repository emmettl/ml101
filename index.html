The learning path

From a straight line to a language model

Each lesson is a ten-minute reading with a live experiment and two checks. One idea runs through all of them: a model is a machine with knobs, and learning is turning the knobs to shrink the error.

  1. Foundations

    A machine with knobs

    What a model is, what it learns, and the one number that says how wrong it is.

    Read lesson Line Fitter lab →

  2. How learning happens

    Rolling downhill

    Gradient descent without the calculus, and why the size of each step decides everything.

    Read lesson Descent Lab →

  3. Generalisation

    Too clever by half

    Why a model that is perfect on its examples can be useless on anything new, and how to catch it.

    Read lesson Overfitting Lab →

  4. Classification

    From numbers to decisions

    One neuron: a line, a squish, and a probability. And the puzzle it cannot solve.

    Read lesson Neuron Lab →

  5. Neural networks

    Stacking neurons

    Layers, and how blame flows backwards through them to reach every knob.

    Read lesson Network Playground →

  6. Representation

    Text becomes numbers

    Tokens and embeddings: how meaning turns into position.

    Read lesson Embedding Lab →

  7. Transformers

    Attention

    How each word decides which other words to listen to.

    Read lesson Attention Lab →

  8. Language models

    Predict the next token

    Generation, temperature, and why a model can recite what it should not.

    Read lesson Next-Token Lab →

  9. Scale

    From toy to ChatGPT

    Pretraining, fine-tuning, feedback, and what changes when the knobs number billions.

    Read lesson Scale Ladder →

  10. Using a model

    Open-book answers

    How a model answers from documents it never trained on: search first, then hand it the page. Retrieval, and where it fails.

    Read lesson Open-Book Lab →
