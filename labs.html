Interactive labs

Run it. Break it. Fix it.

Every lab is a small, real model running live in your browser. Each one asks you to predict what a change will do before it shows you, because being surprised is how intuition gets built.

01Guess

The machine turns an input into an answer using its current knob settings.

02Measure the miss

Compare the guesses with the right answers and boil it down to one number.

03Nudge the knobs

Find which way is downhill for that number, and step that way.

04Check on unseen data

Score it on examples it never trained on. Only that score counts.
