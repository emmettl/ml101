Interactive labs

Run it. Break it. Fix it.

Every lab is a small, real model running live in your browser. Each one asks you to predict what a change will do before it shows you, because being surprised is how intuition gets built.

01Guess

The machine turns an input into an answer using its current knob settings.

02Measure the miss

Compare the guesses with the right answers and boil it down to one number.

03Nudge the knobs

Find which way is downhill for that number, and step that way.

04Check on unseen data

Score it on examples it never trained on. Only that score counts.

Coming with lessons 05–08

Predict first

Each lab has a “Predict before you move it” card. Commit to an answer, then let the lab apply the change. It grades you against its own live numbers.

Read the scope note

Every lab says what it models and what it leaves out. The models are tiny on purpose: small enough to see inside.

Developers: open the code

At the foot of each lab, “Show me the code” reveals the dozen lines the lab is actually running, beside the NumPy equivalent.
